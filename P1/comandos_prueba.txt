=== OPCIÓN 1: EJECUCIÓN CON DOCKER ===
(Recomendado si Docker está instalado en los ordenadores de la universidad)

1. Primero, asegúrate de tener un SECRET_UUID (puedes crear un archivo .env o exportarlo). Si usas docker-compose con la configuración por defecto de la práctica:
   DOCKER_BUILDKIT=0 sudo docker-compose up --build -d
   (Nota: DOCKER_BUILDKIT=0 evita el error "KeyError: 'ContainerConfig'" en versiones antiguas de docker-compose).

2. Ejecuta el cliente automático de pruebas para verificar el funcionamiento:
   python3 cliente.py

3. Para detener los contenedores al terminar:
   sudo docker-compose down


=== OPCIÓN 2: EJECUCIÓN EN LOCAL (SIN DOCKER) ===
(Recomendado si los ordenadores de la universidad tienen restricciones)

1. Crea el entorno virtual (si no lo tienes creado allí) y actívalo:
   python3 -m venv venv/si1p1
   source ./venv/si1p1/bin/activate

2. Instala las dependencias:
   pip install -r requirements.txt

3. Genera un identificador secreto (SECRET_UUID) para compartir entre los servicios. Ejecuta esto y cópialo, o expórtalo en la terminal:
   export SECRET_UUID=$(python3 -c "import uuid; print(uuid.uuid4())")

4. Inicia el microservicio de usuarios (en la PRIMERA terminal):
   python3 user.py

5. Inicia el microservicio de ficheros (abre una SEGUNDA terminal):
   source ./venv/si1p1/bin/activate
   # Asegúrate de exportar el MISMO SECRET_UUID que generaste en el paso 3:
   export SECRET_UUID="<pega_aqui_el_mismo_uuid_del_paso_3>"
   python3 file.py

6. Ejecuta el cliente de pruebas (abre una TERCERA terminal):
   source ./venv/si1p1/bin/activate
   python3 cliente.py
