Requisitos y dependencias:
- Python 3.10+
- numpy
- pandas
- matplotlib
- seaborn
- scipy (requerido para la función clustermap de seaborn)

Instrucciones de ejecución:
1. Asegurarse de tener el archivo data.csv en el mismo directorio que el notebook.
2. Abrir practica2.ipynb en Jupyter Notebook, JupyterLab o VS Code.
3. Ejecutar las celdas de forma secuencial (Kernel -> Restart & Run All).
